# FastAPI Lab 1

Template project for a FastAPI application managed with Poetry.

## Requirements

- Python 3.11+
- Poetry

## Install

```bash
poetry install
```

## Run

```bash
poetry run uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/docs` to view the generated API documentation.

## Test

```bash
poetry run pytest
```
